To add or remove projects from this page, paste a GitHub access token. It's saved only in this browser.

How to make a token (2 minutes, once)
  1. Open GitHub → New fine-grained token.
  2. Name it GDevelop class page and pick an expiry (for example, the end of the year).
  3. Under Repository access, choose Only select repositories → gdevelop-class.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Under Permissions → Account permissions, set Gists to Read and write. This is used to open students' projects privately.
  6. Click Generate token, copy it, and paste it below.

Students: how to get your own copy
  1. Log in at editor.gdevelop.io first.
  2. Click Open in GDevelop on a project below.
  3. In GDevelop, choose File → Save as → GDevelop Cloud. Now it's yours to change.
Students: handing in your project
  1. In GDevelop, open your project and choose File → Save as → Download a copy.
  2. Click Hand in below and attach the .zip file. Only your teacher can see it.
