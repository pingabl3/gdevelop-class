Teacher tools

To add or remove projects from this page, paste a GitHub access token. It's saved only in this browser.

How to make a token (2 minutes, once)
  1. Open GitHub → New fine-grained token.
  2. Name it GDevelop class page and pick an expiry (for example, the end of the year).
  3. Under Repository access, choose Only select repositories → gdevelop-class.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Under Permissions → Account permissions, set Gists to Read and write. This is used to open students' projects privately.
  6. Click Generate token, copy it, and paste it below.

Help requests from students

Students can send you their project when they need help. Their projects are saved privately in your Google Drive. This needs a one-time setup (about 5 minutes).

Set up the help inbox
  1. Sign in to your school Google account, open script.google.com → New project, and name it GDevelop help inbox.
  2. Delete the code that's there, then paste in the inbox script:
  3. Click Save (the disk icon). In the menu next to Run, choose setup, then click Run. Allow access when Google asks.
  4. The Execution log shows a TEACHER KEY. Copy it into the box below.
  5. Click Deploy → New deployment. Click the gear icon, choose Web app. Set Execute as to Me and Who has access to Anyone. Click Deploy.
  6. Copy the Web app URL (it ends in /exec) into the box below, then click Save.

If Anyone isn't offered in step 5, your school limits this. Tell Claude what options you see.

Done requests move to the Done folder in your Drive's GDevelop help requests folder.
